What the map shows

Each dot is a NASA VIIRS 375 m active-fire alert in the current fire season (), coloured by month. One fire can produce several alerts over several days, and heavy smoke or cloud can hide fires, so counts show fire activity, not burned area.

How it updates

The dashboard rebuilds itself automatically twice a day. It checks Global Forest Watch for new VIIRS fire alerts and, when there are any, refreshes every number, map and PDF report. Last update: .

How sites are compared

For each site and province, alerts so far this season are compared with the same calendar period in every year since , using the Global Forest Watch Data API (the data behind PNG DAMS). Each site boundary is registered as a GFW geostore, so its PNG DAMS report opens for that exact boundary.

  • Fires outside a site are counted in a ring around its boundary, using the alert points for the four project provinces. Sites that extend into Simbu, Jiwaka, Enga, Southern Highlands, Central or Morobe have minimum ring counts.
  • Integrated alerts (GLAD-L, GLAD-S2, RADD) count 10–30 m alert pixels, not hectares, and rise in dry, smoky years.
  • Tree cover loss is Hansen/UMD annual loss at more than 30% canopy.
  • District fire density is alerts per 100 km² on GADM 4.1 districts.
  • Proposed Mt Dorohere, Yasina, Artrohialika Lulume and Mt Giluwe, and the Kuk site, have no surveyed boundary yet, so each is a circle of its stated area around its GPS point.
